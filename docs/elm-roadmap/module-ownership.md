## Boundary notes

- `Main` owns Browser.application and port adaptation; `App` owns the pure application model, update transitions, and inbound line fold.
- `Wire`, `Session`, `Isupport`, `Labels`, and `Multiline` own bounded protocol parsing/formatting and request helpers.
- `View` and `View.*` own Elm rendering surfaces; shared state and decisions stay in `App` or focused pure modules.
- Feature modules own their named domain state/validation. Crypto, sockets, browser storage, WebAuthn, media devices, and HTTP remain JS/host-port boundaries as described by `elm/README.md`.
- “No direct Elm test import” is not evidence of no testing or acceptance; acceptance remains tracked separately in `acceptance-ledger.json`.
